# Participant Setup Checklist

Please complete as much of this setup as possible before the workshop. We will leave time for checks at the start, but the day will work much better if accounts and installations are ready in advance.

The workshop starts at **9.30**. Please bring your laptop, charger, and enough time to connect to Wi-Fi before the first hands-on activity.

## Essential Before The Workshop

- Bring a laptop, charger, and working internet access.
- Use a laptop on which you are allowed to install software or use command-line tools.
- Install Codex and confirm that you can open it.
- Install a plain-text editor or code editor such as VS Code.
- Install Git, or confirm that Git is already available.
- Create or confirm access to a GitHub account.
- Create a working folder on your laptop where Codex is allowed to read and write files.
- Do not use sensitive, confidential, identifiable, restricted, or embargoed research data during the workshop exercises.

## Useful If You Can Do It

- Create or confirm access to a free Cloudflare account. We may use this for publishing a simple documentation output, but there will be a local-only path if this is not ready.
- Have a personal email account available for account recovery or signups if institutional restrictions get in the way.
- Install Python 3 if you already use it. The first workshop version should not depend on advanced Python setup.
- Bring a small non-sensitive research folder of your own for reflection or optional adaptation.

## During The Workshop

- We will download or clone the workshop sample project together.
- We will use fictional workshop data for the hands-on exercises.
- You can work in pairs or small groups if your laptop setup differs from your neighbour's.
- Codex will act as the main helper for Git, file organisation, small scripts, and project documentation.

## What We Will Use

- Codex for agentic work with local files.
- `AGENTS.md` for project instructions.
- Agent Skills with `SKILL.md` for reusable workflows.
- Git and GitHub for versioning.
- Cloudflare for publishing a simple output if setup allows.
- Command-line tools or MCP servers for connecting agents to external services if setup allows.
