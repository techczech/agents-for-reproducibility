# Your First Agent Task: Inspect A Messy Folder

This exercise is the first hands-on Codex task. The aim is to see how an agent works with a real folder, asks for permissions, reads files, and proposes changes.

Use the fictional `messy-research-archive/` folder from the workshop sample files.

## Before You Start

Use only the workshop sample files.

Do not use confidential, identifiable, restricted, or embargoed research data.

## Open The Folder

1. Download or extract `workshop-sample-files.zip`.
2. Open Codex.
3. Open the folder:

```text
sample-files/messy-research-archive/
```

## Ask Codex

Start with this prompt:

> Inspect this folder and tell me what is in it. Group the files into likely categories, flag duplicates or confusing names, and suggest a safer folder structure. Do not move, rename, or edit files yet.

Codex may inspect file names, formats, sizes, and short excerpts. It may ask for permission before reading or changing files.

## What To Watch

Notice:

- which folder Codex can access,
- whether it reads files before making claims,
- whether it separates evidence from guesses,
- whether it proposes changes before making them,
- what permissions you approve.

## Debrief Questions

After the task, ask:

> What did you inspect, what did you infer, and what would you change only after human approval?

Discuss:

- What did Codex do well?
- What did it assume?
- What should a researcher check before accepting the plan?
- Which permissions did you give it?

## Optional Next Step

If the facilitator asks you to continue, ask Codex to draft a `data-inventory.md` file. Review the draft before asking it to move or rename anything.
