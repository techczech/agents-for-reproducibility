# Organiser Brief

## Workshop

**Using AI Agents for Reproducible Research**

## Aim

The workshop introduces researchers to AI agents as practical tools for reproducible research workflows. It uses Codex to show how agents can work with local files, documentation, versioning, command-line tools, external services, and simple analysis scripts.

## Recommended Format

The first pilot should be a full-day, in-person workshop with a small cohort and helper support.

A 3-hour version can be developed later as a taster, but the first pilot needs enough time for installation support, Codex basics, `AGENTS.md`, Git/GitHub, Cloudflare, command-line or MCP integration, and a reproducible data-analysis exercise.

## Participants Should Prepare

- Install Codex.
- Install Git or confirm it is already available.
- Create or confirm access to a GitHub account.
- Create or confirm access to a free Cloudflare account.
- Bring a laptop with permission to install software or use command-line tools.
- Avoid bringing sensitive, confidential, identifiable, restricted, or embargoed research data.

## Helper Support

For groups larger than about 25, plan for helpers who can support:

- Codex installation and login.
- Folder permissions and local setup.
- Git and GitHub access.
- Cloudflare account issues.
- Participants who cannot use a particular account or tool on an institutional laptop.
