# Cloud and Publishing Notes

This repository includes workshop material about publishing simple research outputs and documentation using Cloudflare.

## Scope

Cloudflare is used in the workshop as an example of a low-cost way to publish a simple project website or documentation output from a reproducible project folder.

## Current Plan

- Participants should create or confirm access to a free Cloudflare account before the workshop.
- The first pilot should use a simple static output rather than a complex web application.
- Published outputs should be generated from source files in the project folder.
- Any deployment notes should be saved in the project documentation so the output can be recreated.

## Repository Area

- `website/` is reserved for a future public site or Cloudflare-ready output for this workshop repository.
- `exercises/external-services/` is reserved for the Cloudflare and external-service activity design.

## Security

- Do not commit Cloudflare tokens, API keys, account IDs, or private deployment credentials.
- If a workshop exercise needs authentication, document the account setup steps without storing credentials.
- Prefer free-tier workflows that can be explained and repeated by participants.
