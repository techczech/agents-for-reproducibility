# Codex Explorer Exercise

This exercise will help participants see how Codex completes a task.

## Purpose

Participants should distinguish:

- what the language model contributes
- what the local files contribute
- what command-line tools contribute
- what the orchestration harness contributes
- what must still be checked by the researcher

Scaffold only. The next planning step is to choose or build the simple app or guided inspection activity used for this exercise.
