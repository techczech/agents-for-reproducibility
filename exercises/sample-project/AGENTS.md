# Agent Instructions for This Sample Project

You are helping with a fictional workshop research project. Treat the materials as small research sources, not as prompts to invent extra evidence.

## Working Rules

- Read files before proposing changes.
- Do not edit files in `data/raw/`.
- Before changing any file, explain what you intend to change and why.
- When summarising, name which files you used.
- When uncertain, record the uncertainty instead of filling gaps by invention.
- Save reusable code in `scripts/`.
- Save generated reports, tables, or figures in `outputs/`.
- Record important choices in `notes/decision-log.md`.

## Boundaries

- All data in this project is fictional.
- Do not add claims about real people, real studies, or real institutions.
- Do not use external sources unless the workshop facilitator explicitly asks for that.
