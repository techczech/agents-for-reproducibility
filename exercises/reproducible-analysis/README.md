# Reproducible Analysis Exercise

This exercise will use Codex to create or revise a small data-analysis script.

## Source Material

Use `sample-project/data/raw/survey-responses.csv` as the initial dataset.

## Intended Output

The exercise should produce:

- a script in `sample-project/scripts/`
- an output table or report in `sample-project/outputs/`
- a decision-log entry in `sample-project/notes/decision-log.md`

## Teaching Point

The value is not just that Codex can write code. The value is that the script, inputs, outputs, and decisions remain in the project folder for later inspection.
