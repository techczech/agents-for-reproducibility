# Agent Instructions

This folder is the administrative layer for agents working in the sample project.

Keep participant-facing material in the project root, `source-material/`, `outputs/`, and `notes/`. Put reusable agent-only procedure, helper scripts, templates, cache, and scratch material here.

## Layout

- `_AGENT-INSTRUCTIONS/self-healing.md` — correction-to-rule protocol.
- `_AGENT-INSTRUCTIONS/scripts/new-task.py` — helper for `_TASK-LOG/` records.
- `_AGENT-INSTRUCTIONS/templates/` — reusable skeletons if the sample grows.
- `_AGENT-INSTRUCTIONS/cache/` — scratch space; never canonical evidence.

## Rule

Root `AGENTS.md` stays short. If a procedure needs more than a few lines, put the detail here and add a route in `AGENTS.md`.
