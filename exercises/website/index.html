What This Workshop Is

The workshop introduces AI agents as practical tools for reproducible research. It focuses on ordinary research work: files, notes, datasets, scripts, documentation, versioning, and outputs that other people can inspect later.

Agent, Not Chatbot

Participants learn how a language model works inside a wider environment of files, commands, tools, permissions, and feedback.

Reproducibility as Practice

The emphasis is on preserving sources, decisions, scripts, outputs, uncertainty, and review points rather than producing a polished answer once.

Agent Skills

Participants learn how reusable skill folders and SKILL.md instructions can package research workflows for repeated use.

Session Plan

The first version is a full-day in-person workshop. A shorter taster version can be developed later, but the full-day format gives enough time for setup, practice, and review.

  1. Morning

    Codex, Project Folders, and Agent Work

    Install and open Codex, inspect a fictional research folder, and identify what the agent can and cannot safely change.

  2. Morning

    Project Instructions and Skills

    Create AGENTS.md instructions for the project and a small Agent Skill for a repeated research task.

  3. Afternoon

    Versioning and Publishing

    Use Git and GitHub to save a visible project history, then prepare a simple documentation output for publication.

  4. Afternoon

    Analysis and Review

    Run or revise a small analysis task, save scripts and outputs, and decide what a human researcher still needs to check.

Prepare Before You Attend

No programming experience is required, but the workshop works best when participants can use files and folders confidently on their own laptop.

  • Bring a laptop, charger, and working internet access.
  • Install Codex and confirm that it opens.
  • Install Git or confirm that Git is already available.
  • Create or confirm access to a GitHub account.
  • Do not use sensitive, confidential, identifiable, restricted, or embargoed research data in the exercises.
