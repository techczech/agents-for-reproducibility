# Website Draft

This folder contains a static website draft for the workshop page and a future publishing exercise.

Current files:

- `index.html` - workshop page draft.
- `styles.css` - page styling.

The page should stay participant-facing. It should explain what the workshop is, who it is for, what happens during the day, how to prepare, and what participants will take away.

If a generator is added later, treat the generator source as authoritative and do not hand-edit generated output.
