# External Services Exercise

This exercise will show how Codex can work with command-line tools or MCP servers to connect to external services.

## Candidate Example

Sketch Engine is the current candidate example, if setup and access are reliable enough for a workshop.

## Fallback

If Sketch Engine setup is too fragile for the first pilot, use a simpler command-line service or local API-style example.

## Reproducibility Requirement

Any external-service workflow should record:

- which tool or server was used
- what command or instruction was run
- what inputs were sent
- what output was saved
- what cannot be reproduced without external access
