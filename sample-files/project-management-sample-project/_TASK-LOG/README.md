# Task Log

This is the open-task inbox for the sample project.

Create one Markdown file per resumable request:

`_TASK-LOG/<YYYY-MM-DD>-<short-slug>.md`

Use `_TASK-LOG/TEMPLATE.md` or:

```bash
python3 _AGENT-INSTRUCTIONS/scripts/new-task.py "Short task title"
```

Task logs are operational records. Use `_CHANGELOG/` for meaningful change history, backlog, and durable decisions.
