# Use PM9 Change Request Scenario

## Decision

## Context

The scenario naturally exercises source reading, impact analysis, option framing, sponsor wording, task logging, and decision tracking.

## Consequences

Participants can inspect a small but realistic project-management workspace without handling private or sensitive material.
