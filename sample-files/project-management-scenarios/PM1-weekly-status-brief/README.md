# PM1 Weekly Status Brief

## Prompt

You are supporting a project manager. Use the files in this folder to produce a weekly project status brief for the sponsor.

Return:
- a one-paragraph executive summary,
- RAG status for scope, schedule, budget, risks, and stakeholder confidence,
- top 5 accomplishments,
- top 5 next-week priorities,
- decisions needed from the sponsor,
- a short "watch list" of risks and issues.

Keep it concise and suitable for a senior stakeholder who will read it in under two minutes. Use only the supplied material; mark uncertainties clearly.

## Files

- `weekly-notes.md`
- `task-export.csv`
- `sponsor-style.md`
