# PM2 Meeting Prep Pack

## Prompt

Prepare a meeting pack for the weekly project board. Use the agenda request, previous meeting notes, and background in this folder. The PDF is included only as a formatting reference for how formal minutes tend to capture decisions and action items.

Return:
- meeting purpose,
- proposed agenda with timings for a 45-minute meeting,
- pre-read summary,
- decisions needed,
- questions to ask in the meeting,
- draft minutes skeleton ready to fill in live.

## Files

- `agenda-request-email.md`
- `previous-meeting-notes.md`
- `project-board-background.md`
- `sandiego-sample-meeting-minutes-2018.pdf`

## Measurement Notes

This tests meeting preparation, agenda design, and transforming loose context into a usable meeting artefact.
