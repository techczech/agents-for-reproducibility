# Shared Project Background

The project is the Customer Service Booking Portal, a six-month initiative for a mid-sized public-sector services team. The aim is to replace email-based booking requests with a web form, routing workflow, staff dashboard, and basic reporting pack. The core delivery team includes a project manager, service owner, business analyst, content designer, supplier delivery lead, data protection adviser, and two service representatives.

The project is not politically sensitive, but it is visible because the current process creates delays, duplicate requests, and inconsistent responses. The sponsor wants a pragmatic pilot in two service areas before wider rollout. Accessibility, data protection, staff adoption, and clear handover are the main non-negotiables.
