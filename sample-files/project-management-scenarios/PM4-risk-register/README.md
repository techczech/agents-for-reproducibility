# PM4 Risk Register

## Prompt

Use the project notes and current risk snapshot to update a risk register. You may inspect the included programme/project log spreadsheet for field ideas, but produce the answer as a Markdown table.

Return:
- revised risk register with probability, impact, score, owner, mitigation, contingency, and review date,
- top 3 risks requiring escalation,
- risks that should be closed or merged,
- assumptions you made.

## Files

- `risk-notes.md`
- `current-risk-register.csv`
- `govie-programme-and-project-log.xlsm`

## Measurement Notes

This tests spreadsheet/template inspection, structured extraction, scoring judgement, and escalation logic.
