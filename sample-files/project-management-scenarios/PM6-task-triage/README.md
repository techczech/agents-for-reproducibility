# PM6 Task Triage

## Prompt

Triage the task export and email-action notes. Produce:
- immediate blockers,
- tasks to do this week,
- tasks to defer,
- duplicate or unclear tasks,
- recommended next-week execution plan by day,
- five clarification questions the project manager should ask.

Be explicit about why you prioritised each blocker.

## Files

- `task-board-export.csv`
- `email-action-fragments.md`

## Measurement Notes

This tests prioritisation, de-duplication, dependency analysis, and work planning from a messy task board.
