# PM7 Project Plan From Brief

## Prompt

Turn the project brief into a practical project plan outline. Use the included public templates as inspiration if useful, but do not fill out every template field mechanically.

Return:
- project objectives and scope boundaries,
- deliverables,
- workstreams and milestones,
- governance and reporting rhythm,
- dependency map,
- assumptions,
- first 10 actions for the project manager.

## Files

- `project-brief.md`
- `constraints.md`
- `govie-project-charter.docx`
- `govie-project-plan-template-guide-notes.docx`

## Measurement Notes

This tests planning from a rough brief, template use, and avoiding over-elaborate output.
