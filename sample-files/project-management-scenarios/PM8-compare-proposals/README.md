# PM8 Compare Proposals

## Prompt

Compare the two supplier proposals using the evaluation criteria. Produce:
- score table out of 5 for each criterion,
- short rationale for each score,
- key risks for each supplier,
- questions to ask before award,
- recommendation with confidence level.

Do not choose only on price. Treat delivery risk, accessibility, reporting, support, and organisational fit as meaningful.

## Files

- `evaluation-criteria.md`
- `proposal-a.md`
- `proposal-b.md`

## Measurement Notes

This tests comparative judgement, weighting, procurement-style reasoning, and evidence-based recommendation.
