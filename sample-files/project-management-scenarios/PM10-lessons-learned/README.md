# PM10 Lessons Learned

## Prompt

Use the retrospective notes, incident log, and final status note to draft a lessons-learned summary for the project manager.

Return:
- what worked well,
- what did not work well,
- root causes,
- recommendations for future projects,
- reusable checklist for the next pilot,
- short closure note for the sponsor.

Use the included public post-project review template only as a reference for the kind of topics a closure review may cover.

## Files

- `retrospective-notes.md`
- `incident-log.csv`
- `final-status.md`
- `govie-post-project-completion-review-report.docx`
