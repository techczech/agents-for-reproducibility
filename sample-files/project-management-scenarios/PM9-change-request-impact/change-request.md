# Change Request

Request: Include online payments in pilot one so users can pay at the point of booking.

Reason given: Some service users currently receive a payment link later, which creates extra emails and occasional missed payments. Sponsor asked whether excluding payments creates a poor user experience.

Proposed by: Service owner.

Requested decision date: 2026-05-15.

Known implications:
- Supplier says payment integration is a separate workstream.
- Finance would need reconciliation rules and test cases.
- Data protection wording may need to change if payment references are stored.
- Staff training would need to cover payment exceptions and refunds.
