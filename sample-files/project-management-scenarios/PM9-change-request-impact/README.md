# PM9 Change Request Impact

## Prompt

Assess the change request against the baseline plan. Produce:
- decision summary,
- impact on scope, schedule, cost, quality, data protection, training, and stakeholder communications,
- options with pros and cons,
- recommended decision,
- sponsor-ready wording.

Be clear where the evidence is insufficient.

## Files

- `baseline-plan.md`
- `change-request.md`
- `current-status.md`

## Measurement Notes

This tests impact analysis, option framing, and sponsor-level decision writing.
