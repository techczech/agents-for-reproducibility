# PM5 Stakeholder Update Email

## Prompt

Draft stakeholder communications from the supplied status notes. Produce three versions:
- sponsor email, maximum 180 words,
- delivery-team update, maximum 250 words,
- pilot-staff message, maximum 180 words.

Use the audience notes to adapt tone and content. Avoid pretending everything is fine. Be clear about decisions, asks, and dates.

## Files

- `status-notes.md`
- `audience-notes.md`
- `govie-project-communications-plan.xlsx`

## Measurement Notes

This tests audience adaptation, compression, and converting project detail into practical communications.
