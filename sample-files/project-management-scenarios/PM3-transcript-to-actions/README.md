# PM3 Transcript To Actions

## Prompt

Use the transcript in this folder to produce structured project follow-up.

Return:
- concise meeting summary,
- decision log,
- action log with owner and due date,
- risks or issues raised,
- unresolved questions,
- a follow-up email to attendees.

Do not invent missing owners or dates. If they are implied but not explicit, mark them as inferred.

## Files

- `meeting-transcript.txt`
- `attendees.md`

## Measurement Notes

This tests long-context extraction, attribution, and disciplined handling of ambiguity.
