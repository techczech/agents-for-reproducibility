# Workshop Sample Files

This folder contains downloadable sample material for the hands-on parts of the workshop.

The files are designed for participants to copy to their own machine, open in Codex, and practise ordinary reproducibility tasks: inspecting a folder, making an inventory, documenting sources, organising files, checking assumptions, and saving useful outputs.

## Folder Index

- `project-management-scenarios/` contains ten practical knowledge-work scenarios copied from a public-workshop fixture set. These are useful for exercises about briefing, synthesis, meeting preparation, risk registers, task triage, and stakeholder updates.
- `project-management-sample-project/` contains a small agent-ready project built around a fictional change-request impact review. This is useful for inspecting `AGENTS.md`, `_TASK-LOG/`, `_CHANGELOG/`, source material, and generated-output folders together.
- `research-data-for-replication/` contains a small public research dataset with both cleaned and raw CSV files. This is useful for exercises about documenting data provenance, reproducing a simple analysis, and checking variable definitions.
- `messy-research-archive/` contains fictional mock files in a deliberately untidy folder. This is useful for exercises about asking Codex to inspect, inventory, classify, and reorganise research materials safely.

## Download Bundle

The repository also includes `workshop-sample-files.zip` at the repository root. Participants can download that zip, extract it, open the extracted folder in Codex, and work locally.

## Safety Notes

- The messy archive uses fictional mock data only.
- The project-management scenarios use synthetic working data and public reference templates.
- The project-management sample project uses fictional source material copied from the PM9 scenario.
- The replication data comes from the public Palmer penguins dataset. See `research-data-for-replication/README.md` for source and citation details.
- Participants should not add real participant data, sensitive research material, API keys, or private account information to these sample folders.
