# Rough Literature Notes

These are fictional notes for a workshop exercise. They imitate the kind of rough notes a researcher might bring into a project folder.

## Note L01: Reproducibility as Practice

- Reproducibility depends on more than final outputs.
- Important elements: documented sources, clear methods, stable file names, saved scripts, and records of decisions.
- Possible quote to verify later: "reproducibility is a social and technical practice".

## Note L02: AI Assistance in Research Workflows

- AI tools can help with drafting, summarising, coding, data cleaning, and scripting.
- Risk: generated summaries can detach claims from sources.
- Important distinction: assistance with process vs delegation of interpretation.

## Note L03: Local Agents and Project Folders

- Agents working in a local folder can inspect multiple files and create durable outputs.
- Benefits: repeatable scripts, documentation, folder-level context.
- Risks: accidental access to sensitive files, unclear permissions, overconfident edits.
