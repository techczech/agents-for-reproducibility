# Sample Research Project: AI Tools in Everyday Research Work

This fictional mini-project is used in the workshop "Using AI Agents for Reproducible Research".

The project explores how researchers decide whether to use AI tools in everyday research work. It includes short interview excerpts, a small survey table, and rough literature notes. All materials are fictional and safe to use in a workshop.

## Research Question

How do researchers describe the benefits, risks, and practical boundaries of using AI tools in their research workflows?

## Current State

This project has raw materials but incomplete documentation. During the workshop, participants will use an AI agent to inspect the folder, improve the documentation, create a data inventory, run or revise a small analysis task, and produce a short report.

## Folder Guide

- `data/raw/` contains the original fictional materials.
- `data/processed/` is for cleaned or transformed files.
- `docs/` is for project documentation.
- `notes/` is for research questions, decisions, and working notes.
- `scripts/` is for reusable scripts.
- `outputs/` is for reports, tables, figures, or web pages.

## Reproducibility Rule

Do not overwrite raw materials. Any change, cleaning step, or analysis should leave a trace in the notes, scripts, or outputs.
