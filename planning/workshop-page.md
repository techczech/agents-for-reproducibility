# Workshop Page

## Title

Using AI Agents for Reproducible Research

## Registration Abstract

This workshop introduces the use of AI agents to help researchers produce more reproducible research workflows from data management to data analysis - for both qualitative and quantitative data. Using Codex as the main example of a coding agent, it shows how agents fit into ordinary computer work and how they can make documentation, data management, versioning, reusable agent instructions, and dissemination practices easier to apply consistently.

Participants will learn the difference between the language model inside an agent and the surrounding computing infrastructure: files, folders, command-line tools, Git, GitHub, cloud services, external tools, `AGENTS.md`, and Agent Skills. The workshop shows how to use Codex to organise research materials, inspect data, create project documentation, and set up instructions that ask the agent to log decisions, preserve evidence, reuse tested workflows, and support reproducibility throughout the research process.

The morning introduces Codex, local project folders, the anatomy of an agent task, and the design of project instructions. The afternoon focuses on Agent Skills, versioning with Git and GitHub, publishing a simple project output, connecting to an external tool where appropriate, and using Codex for a small data-analysis task while preserving scripts, inputs, outputs, and decisions.

The workshop is suitable for researchers, research students, research support staff, and professional services colleagues who work with documents, transcripts, spreadsheets, notes, or small datasets. No programming experience is required, but participants should be comfortable working with files and folders on their own laptop and should install Codex before attending.

## Short Version

This workshop introduces AI agents as practical tools for reproducible research. Using Codex, participants will learn how agents combine language models with files, folders, command-line tools, Git, GitHub, publishing tools, external services, `AGENTS.md`, and Agent Skills. The session covers project organisation, reusable `SKILL.md` instructions, decision logging, versioning, simple publishing, and a small data-analysis task. The emphasis is on making good research and data-management practices easier to inspect, share, and repeat.

## Audience

Researchers, research students, research support staff, and professional services colleagues who work with documents, transcripts, spreadsheets, notes, small datasets, or research outputs.

## Prerequisites

No programming experience is required. Participants should be comfortable working with files and folders on their own laptop and should install Codex before attending.

## What Participants Will Build

Participants will work with a fictional research-project folder. During the session they will use Codex to inspect the materials, improve the documentation, create project instructions, create a small Agent Skill, record decisions, version the project, publish a simple output, and run or revise a small analysis task.
