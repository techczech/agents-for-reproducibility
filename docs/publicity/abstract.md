# Public Abstract

## Title

Using AI Agents for Reproducible Research

## Registration Abstract

This workshop introduces the use of AI agents to help researchers produce more reproducible research workflows. Using Codex as the main example, it will show how agents work, how they fit into ordinary computer work, and how they can make good documentation, data management, versioning, and dissemination practices easier to apply consistently.

Participants will learn the difference between the language model inside an agent and the surrounding computing infrastructure: files, folders, command-line tools, Git, GitHub, cloud services, and external APIs. The workshop will show how to use Codex to organise research materials, inspect data, create project documentation, and set up `AGENTS.md` and skill files that instruct the agent to log decisions, preserve evidence, and support reproducibility throughout the research process.

The morning will cover first steps with Codex, a simple exploration of how an agent completes tasks, and the design of project instructions. The afternoon will focus on versioning with Git and GitHub, publishing a simple project website with Cloudflare, and using command-line tools or MCP servers to connect agents to external services such as Sketch Engine. The workshop will finish with a simple data-analysis example showing how coding agents can help write or revise code while keeping scripts, inputs, outputs, and decisions recorded.

The workshop builds on earlier sessions on coding agents for project management and research data management, but gives the reproducibility question its own practical focus. It is suitable for researchers, research students, research support staff, and professional services colleagues who work with documents, transcripts, spreadsheets, notes, or small datasets. No programming experience is required, but participants should be comfortable working with files and folders on their own laptop and should install Codex before attending.

## 80-Word Version

This workshop introduces AI agents as practical tools for reproducible research. Using Codex, participants will learn how agents combine language models with files, folders, command-line tools, Git, GitHub, Cloudflare, and external services. The session covers project organisation, `AGENTS.md` instructions, logging decisions, versioning work, publishing simple outputs, and using agents for a small data-analysis task. The emphasis is on making good reproducible research and data-management practices easier to apply, inspect, share, and repeat across everyday research workflows on participants' computers.

## Audience

Researchers, research students, research support staff, and professional services colleagues who work with documents, transcripts, spreadsheets, notes, small datasets, or research outputs.

## Prerequisites

No programming experience is required. Participants should be comfortable working with files and folders on their own laptop and should install Codex before attending.
